===============================================================================
📋 PROJE ÖZETİ
===============================================================================

Bu proje, AlpSoft Servis Takip Yazılımı için geliştirilmiş, kasa ve parça 
yönetimini otomatikleştiren kapsamlı bir sistemidir.

Teknoloji Stack:
  • Platform: .NET Framework 4.7.2
  • UI Framework: WPF (Windows Presentation Foundation)
  • Veritabanı: SQL Server
  • Dil: C# 7.0+, XAML
  • Tasarım Deseni: MVVM (kısmen)
