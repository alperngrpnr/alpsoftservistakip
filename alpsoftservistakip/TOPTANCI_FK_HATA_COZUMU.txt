🐛 SORUN (Neden Hata Alıyordunuz?)

SQL Script çalıştırılırken:
  ❌ Foreign key 'FK_Toptancilar_Sirket' references invalid table 'Sirketler'.
  ❌ Foreign key 'FK_ToptanciParcaAlimlar_Sirket' references invalid table 'Sirketler'.

Neden?
  → Veritabanında Sirketler tablosu yoktu
  → Script bunu kontrol etmeden FK eklemeye çalışıyordu
  → SQL Server FK ekleyemediği için hata veriyordu

═══════════════════════════════════════════════════════════════════

✅ ÇÖZÜM (Ne Yaptığımız)

Script'i Yeniden Yazıldı:
  ✅ CREATE TABLE ile FK'yi aynı anda ekleme ❌ (Eski)
  ✅ Tablolayı FK'siz oluştur (Yeni)
  ✅ Sonra ALTER TABLE ile FK'yi ekle (sadece varsa) (Yeni)

Adımlar:
  1️⃣ Sirketler tablosu var mı? → Kontrol et
  2️⃣ Toptancilar ve ToptanciParcaAlimlar tabloları oluştur (FK'siz)
  3️⃣ Sirketler varsa → ALTER TABLE FK_Toptancilar_Sirket ekle
  4️⃣ Kayitlar varsa → ALTER TABLE FK_ToptanciParcaAlimlar_Kayit ekle

Sonuç:
  ✅ Sirketler varsa = Tüm FK'ler eklenir
  ✅ Sirketler yoksa = Tablolar yine oluşturulur, FK's'iz
  ✅ Daha sonra Sirketler tablosu eklenirse = FK'ler sonra eklenebilir

🔍 SQL SCRIPT DETAYLARı

Eski Kod (Hataydı):
──────────────────
CREATE TABLE Toptancilar (
    ...
    CONSTRAINT FK_Toptancilar_Sirket FOREIGN KEY (SirketID) 
    REFERENCES Sirketler(ID)  ← HATA! Sirketler yoksa çöküyor
)

Yeni Kod (Çalışıyor):
────────────────────
-- Adım 1: Tablo FK'siz oluştur
CREATE TABLE Toptancilar (
    ...
    CONSTRAINT UQ_Toptancilar_FirmaAdi UNIQUE(SirketID, FirmaAdi)
)

-- Adım 2: Sirketler varsa FK ekle
IF EXISTS (SELECT * FROM sys.objects WHERE object_id = 
           OBJECT_ID(N'dbo.Sirketler'))
BEGIN
    IF NOT EXISTS (SELECT * FROM sys.foreign_keys 
                   WHERE name = 'FK_Toptancilar_Sirket')
    BEGIN
        ALTER TABLE Toptancilar
        ADD CONSTRAINT FK_Toptancilar_Sirket 
        FOREIGN KEY (SirketID) REFERENCES Sirketler(ID)
    END
END
