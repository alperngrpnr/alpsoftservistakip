🚀 KULLANMAYA BAŞLAMAK İÇİN

1. SQL TABLOLARINI OLUŞTUR
   ──────────────────────────
   📂 Dosya: SQL_Scripts/Toptancilar_CreateTable.sql
   📋 Nerede: SQL Server Management Studio

   • SSMS'de yeni sorgu aç
   • SQL dosyasının içeriğini yapıştır
   • F5 tuşu ile çalıştır
   ✅ İşlem tamamlandı

2. UYGULAMA BAŞLAT
   ─────────────────
   💻 Komut: dotnet run
   ⏱️ Bekleme süresi: ~5-10 saniye
   ✅ Uygulama açıldı

3. TOPTANCI YÖNETİMİNE GİT
   ────────────────────────
   🖱️ Tıkla: Ana Menü → 👨‍💼 TOPTANCI YÖN.
   ✅ Sayfa açıldı

4. İLK TOPTANCI EKLE
   ──────────────────
   🔘 Tıkla: ➕ YENİ TOPTANCI EKLE
   📝 Doldur: Adı, Telefon, IBAN (opsiyonel)
   💾 Kaydet: KAYDET butonuna tıkla
   ✅ Toptancı eklendi

📊 VERİTABANI TABLOSU

Toptancilar
├─ ID (PRIMARY KEY)
├─ SirketID (FOREIGN KEY → Sirketler)
├─ FirmaAdi (UNIQUE per SirketID)
├─ Telefon
├─ IBAN
├─ Aciklama
├─ OlusturulmaTarihi
└─ GuncellemeTarihi

ToptanciParcaAlimlar
├─ ID (PRIMARY KEY)
├─ SirketID (FOREIGN KEY → Sirketler)
├─ ToptanciID (FOREIGN KEY → Toptancilar)
├─ KayitID (FOREIGN KEY → Kayitlar, optional)
├─ ParcaAdi
├─ Adet (CHECK > 0)
├─ BirimFiyati
├─ ToplamTutar
├─ OdenenTutar (DEFAULT 0)
├─ BorcluTutar (DEFAULT 0)
├─ Aciklama
├─ IslemTarihi
├─ OlusturulmaTarihi
└─ GuncellemeTarihi
